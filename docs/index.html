Call an AI agent
right from your shell_

Type a request and clam hands it to an LLM or coding agent. Type a command and your shell runs it, untouched. Nothing changes without a y.

[c+] ~/weather-cli $ ls
index.js api.js package.json
[c+] ~/weather-cli $ what does this project do?
reading index.js, api.js, package.json…
A tiny weather CLI. index.js takes a city (default Lisbon)
and prints a one-line forecast fetched from wttr.in.
[c+] ~/weather-cli $ add a help option to the cli
clam requests write_file: index.js
+ if (city === '--help' || city === '-h') {
+ console.log('Usage: weather-cli [city]');
+ process.exit(0);
+ }
Allow this action? [y/N] y
Added -h and --help. They print usage and exit.
[c+] ~/weather-cli $ git diff --stat
index.js | 12 ++++++++++--
[c+] ~/weather-cli $ node index.js --help
Usage: weather-cli [city]
[c+] ~/weather-cli $

SYNOPSIS

clam init bash | zsh | pwsh
clam [on | off | reset]
clam auto [on | off]
any request for the agent

DESCRIPTION

Puts an AI agent one Enter away in Bash, zsh, PowerShell and Vim, without getting in the way of the shell: commands run exactly as they would without clam, and there is no separate chat window or mode to switch into. Requests go to the agent, which can read your project; anything that writes a file or runs a command asks first. Use the built-in agent with any OpenAI-compatible API, or one you already have: Codex, Claude Code, OpenCode, pi, or any command. One static binary for Linux, macOS, Windows and FreeBSD.

INSTALL

$ curl -fsSL https://raw.githubusercontent.com/dh1011/clam/main/install.sh | sh
$ export OPENAI_API_KEY=sk-...
$ echo 'eval "$(clam init bash)"' >> ~/.bashrc

The script picks the right binary for your OS and CPU, checks its SHA-256 checksum and installs it to ~/.local/bin. No runtime to install. For zsh, use clam init zsh in ~/.zshrc; for PowerShell, download the Windows .exe from the latest release and add clam init pwsh | Out-String | Invoke-Expression to $PROFILE. To build from source, run make with Go 1.24+.

PLATFORMS

Shells: Bash, zsh, PowerShell (with PSReadLine), Vim and Neovim.
Systems: Linux (amd64, arm64, armv7, 386), macOS (Intel, Apple silicon), Windows (amd64, arm64), FreeBSD (amd64, arm64).
Agents: built-in (OpenAI-compatible), Codex, Claude Code, OpenCode, pi, or any command.

HOW IT WORKS

  you press Enter
        |
   shell hook ---- starts with a command -----> runs as usual
        |                                              ^
   clam check ---- not a request ----------------------'
        |
     request
        |
      agent ------ read / list / search files --> answer
        |
   write or run? -- Allow? [y/N] -- y --> action runs

The check runs locally and gives up after a second, so the prompt never waits on the network. Commands never reach the agent.
